# PauseCart

A waiting shelf for things you want, but are not buying yet. When the wait ends, you choose still want, later, or let it go. A let-go total is not money saved.

Package: `com.PauseCartMNG.PauseCart`

Remote config: [N307.json](https://api2.blwsmartware.net/N307.json) — `disable=1` hides Google Play Billing popups only. Shop stays open for coin unlocks.

| Product ID | Type |
| --- | --- |
| `pc_pack_1` … `pc_pack_10` | Consumable coins |
| `pc_remove_ads` | Non-consumable |
| `pc_pro` | Non-consumable, more than 8 waiting items |

Names, prices, links, and decisions stay on the device. No account, and no store page is fetched.
